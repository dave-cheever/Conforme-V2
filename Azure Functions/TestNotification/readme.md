Call `/api/TestNotification` with `notificationName` in the query with name of the notification to be tested.
e.g. `/api/TestNotification?notificationName=sendAuditsDigest`

Available notifications:

- sendAuditsDigest
- sendMissedAudits
- sendOverdueActions
- sendTrackerResponseDigest
- sendTrackerResponseReminder
- sendUpcomingAudits
